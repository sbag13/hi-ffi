# Java Integration Guide

This directory contains an integration test for the Java bindings generated by
`hi-ffi`. The test builds the Rust library, compiles the generated Java sources
and `Main.java`, then runs the Java tests against the native library.

## Prerequisites

- Rust toolchain
- JDK 21 (the Foreign Function & Memory API is used with preview enabled)
- A supported native build environment for the Rust library

## Build and Run

From this directory, run:

```bash
bash test_java.sh
```

The script builds the Rust test crate, generating Java sources under
`tests/generated_code/java/` and the native library under `tests/target/debug/`.
It then compiles the generated sources and `Main.java` with Java 21 preview
features enabled, and runs the integration tests. Compiled Java classes are
written to the local `classes/` directory.

The script can also be run from any working directory:

```bash
/path/to/hi-ffi/tests/java/test_java.sh
```

## Coverage

`Main.java` exercises generated structs and methods, including optional values,
`Result` error handling, vectors, enums, and trait objects. Java-facing APIs use
native Java types such as `Optional` and `List`; generated glue handles
conversions to and from Rust's FFI representations. Rust-owned trait objects
are exposed as Java interfaces that extend `AutoCloseable`.
